# Tradingmaster — Project Plan

## Vision

The go-to Indian trading education + utility platform. Real tools first,
education second, monetization (AdSense) only on top of genuine value.

## Audience

Indian traders — beginners learning the basics through advanced users
sizing futures positions and checking true option trade costs.

## Phases

### Phase 1 (in progress)
- [x] Fee research for both calculators
- [ ] Site shell — modern trading UI, 3D touches, animated but fast
- [ ] Crypto futures position-size calculator (Delta Exchange India fees)
- [ ] Indian options total-cost calculator (full statutory charges)
- [ ] 100 rotating trading quotes on homepage
- [ ] Trust/legal pages: About, Contact, Privacy Policy, Terms,
      Disclaimer, Advertising Disclosure
- [ ] Initial core articles

### Phase 2
- Free beginner trading course (structured lessons)
- Option trading guides, stop-loss & risk management, trading psychology
- Keyword-research-driven articles + FAQs with strong internal linking

### Phase 3
- SEO hardening: sitemap, crawlability, mobile UX, Core Web Vitals
- AdSense application once content depth + policy compliance are solid

## Non-negotiables

- Risk-first education; no get-rich-quick claims
- Original, substantial content (no thin/duplicate pages)
- Mobile-first, fast loading
- Fee figures verified against official sources, with override controls
  in calculators and dated research notes in `docs/`
